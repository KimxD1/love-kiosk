=====================================================
 사랑의 카페 - 유아교육용 카페 역할놀이 키오스크
=====================================================

■ 사용 방법 (프로그래밍 지식 필요 없음)

1. 이 폴더(love-cafe) 전체를 원하는 위치에 저장하세요.
2. index.html 파일을 더블클릭하면 크롬(Chrome) 브라우저에서 바로 실행됩니다.
3. 태블릿에서 사용할 때는 이 폴더를 웹서버(또는 GitHub Pages 등)에 올린 뒤
   해당 주소를 Android Chrome으로 열어주세요. (NFC 기능은 HTTPS 환경에서만 동작)

■ 폴더 구조

love-cafe/
├─ index.html              ← 실제 사이트 파일 (이 파일만 열면 바로 동작)
├─ README.txt              ← 이 설명서
├─ images/
│  ├─ sign/
│  │  └─ love-cafe-sign.png   ← 아이들이 만든 하트 간판 사진 (이미 넣어드렸습니다)
│  ├─ snacks/               ← 과자 이미지를 넣는 곳 (지금은 비어있음 → 이모지로 표시됨)
│  └─ drinks/                ← 음료 이미지를 넣는 곳 (지금은 비어있음 → 이모지로 표시됨)
└─ audio/                   ← 화면별 음성 안내 mp3를 넣는 곳 (지금은 비어있음 → 무음)

■ 상품 이미지를 다시 다른 사진으로 바꾸고 싶다면

위 "파일명"과 정확히 똑같은 이름으로 이미지 파일(PNG 권장, 정사각형에 가까울수록 예쁨)을
images/snacks 또는 images/drinks 폴더에 덮어쓰기만 하면 됩니다.
코드를 전혀 수정하지 않아도 자동으로 새 사진으로 바뀝니다.

■ 메뉴(가격) 수정 방법

index.html 파일을 열면 <script> 태그 안쪽 위에 SNACKS, DRINKS 라는 두 개의 목록이 있습니다.
"과자 하나 추가해줘", "빼빼로 가격을 1600원으로 바꿔줘" 처럼 말씀해주시면
제가 수정된 완성 파일을 다시 만들어드립니다. 직접 코드를 건드리실 필요는 없습니다.

■ 결제 기능에 대한 중요 안내

이 사이트의 카드결제 화면은 Web NFC API(Android + Chrome 전용)로 NFC 태그를 인식하는
기능이며, 실제 신용카드 결제(승인/매입)가 이루어지는 것이 아닙니다.
실제 금융 결제를 연동하려면 별도의 PG사(결제대행사) 연동과 결제 단말기가 필요합니다.

■ 기존 "열매 ㄱㄴㄷ 뷔페" 사이트와의 관계

이 파일은 완전히 독립된 새 폴더(love-cafe)이며, 기존 index.html은 전혀 건드리지
않았습니다. 두 사이트를 같은 프로젝트 안에 함께 두셔도 서로 영향을 주지 않습니다.
